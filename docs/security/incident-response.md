# Vulnerability and CRA incident response

1. Record report time, reporter, affected versions, product impact, exploit status, and evidence in the confidential incident record.
2. Triage severity and exploitation status within five business days; preserve logs and release artifacts without exposing reporter or customer data.
3. For an actively exploited vulnerability or severe incident, submit the CRA Single Reporting Platform early warning within 24 hours of awareness and the full notification within 72 hours.
4. Deliver a security update as soon as practicable. File the final report within 14 days after the corrective measure for an actively exploited vulnerability, or within one month after the 72-hour notification for a severe incident.
5. Publish a coordinated advisory after users can apply the fix, unless delaying disclosure produces lower user risk. Include affected product identifiers, impact, severity, remediation, and fixed versions.
6. Complete a post-incident review, update the threat model and tests, and retain evidence with the product technical file.
