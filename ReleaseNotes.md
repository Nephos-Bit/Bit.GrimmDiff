# GrimmDiff 0.1.8

## Deutsch

- Die Diff-Ansicht zeigt die tatsächlichen alten und neuen Dateizeilennummern direkt neben den jeweiligen Codezeilen an.
- Zeilennummern in der Diff-Ansicht überlagern nicht mehr die Änderungsmarkierungen.
- Texte in transparenten Aktionen bleiben im Light-Theme lesbar; beim Hover wechseln sie passend zum dunklen Aktionshintergrund.
- Die Repository-Informationsleiste lässt sich über die linke Werkzeugleiste ein- und ausklappen.

## English

- The diff view now shows the actual old and new file line numbers directly beside the corresponding code lines.
- Line numbers in the diff view no longer overlap change markers.
- Text in transparent actions remains readable in the light theme and changes to match the dark action background on hover.
- The repository information panel can now be collapsed and expanded from the left toolbar.
