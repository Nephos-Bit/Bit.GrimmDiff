# GrimmDiff 0.1.10

## Deutsch

- Die Breite von Analyse- und Diff-Bereich lässt sich nun über einen sichtbaren Trenner anpassen.
- Der Trenner macht die Grenze zwischen Analyse und Diff klar erkennbar.
- Beim Anpassen bleibt dem Diff-Bereich ausreichend Platz zum Arbeiten erhalten.
- Ein erneuter Klick auf das Zahnrad kehrt aus den Einstellungen zur Hauptansicht zurück.

## English

- You can now resize the analysis and diff panes using a visible splitter.
- The splitter makes the boundary between analysis and diff clearly visible.
- The diff pane retains enough room to work while resizing.
- Clicking the gear again returns from settings to the main view.
