# GrimmDiff 0.1.9

## Deutsch

- Auswahlfelder in den Einstellungen entsprechen nun der technischen Oberflächengestaltung.
- Das verfügbare wöchentliche KI-Kontingent wird neben dem angemeldeten ChatGPT-Konto angezeigt.
- Neue Einstellungsseite mit klar gegliederten Bereichen für Darstellung, KI, Integrationen und Updates.
- Ticketreferenzen in Commit-Betreffzeilen können für Jira, GitHub, GitLab oder Azure DevOps global verlinkt werden.
- Einstellungen und ihre Hinweise wechseln nun direkt zwischen Deutsch und Englisch.
- Die festen Gruppierungsanweisungen für die Codex CLI können in den KI-Einstellungen schreibgeschützt eingesehen werden.

## English

- Selection fields in settings now match the technical interface design.
- The available weekly AI quota is shown beside the signed-in ChatGPT account.
- New settings page with clearly structured areas for appearance, AI, integrations, and updates.
- Ticket references in commit subjects can be linked globally for Jira, GitHub, GitLab, or Azure DevOps.
- Settings and their guidance now switch directly between German and English.
- The fixed grouping instructions for the Codex CLI can be viewed read-only in the AI settings.
